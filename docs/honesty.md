# 诚实性说明：本仓库度量了什么，没有度量什么

这份说明与代码同等重要。任何使用、引用或二次开发本项目的读者都应先读它。

## 度量的是机制，不是模型

`hypoarena` 验证的是发现流水线的**机制正确性**：

- 图结构不变量（无重复 ID、边端点存在、算子保持有效性）；
- grounding 校验能否抓住编造引用、数字漂移与否定翻转；
- Bradley–Terry / Elo 更新能否在**脚本化**对手上恢复植入的技能顺序；
- 去重指标（Jaccard / TF-IDF cosine / MinHash LSH）在带植入改写簇的合成语料上的
  recall 与 precision；
- 贝叶斯累积的单调性与先验敏感性；
- 检查点续跑与一次性运行产生逐字节相同的产物。

这些性质都可以通过确定性测试验证，它们**不**说明任何真实语言模型具备科学发现能力。

## 数字来自哪里

所有量化数字都来自本仓库生成的**合成语料**：由固定 seed 的生成器构造论文式文本，
其中人工植入因果链、竞争假设与改写簇，然后度量流水线恢复这些植入结构的程度。
因此这些数字的含义是“机制在已知真值的合成数据上的表现”，不是文献抽取或科研能力的评测。

## 适配器 ≠ 模型评测

- **脚本化 agent**：按固定规则产生响应，用于验证循环控制与数据结构。
- **回放 agent**：从 JSONL fixture 读取预先记录的响应，用于验证解析与状态机。
- **HTTP 适配器**：面向 OpenAI 兼容接口的通用客户端（超时、重试、可重试状态码），
  测试**只**连接本地 loopback mock server；仓库中不存在真实端点调用，也不读取密钥。

区分这三者与“真实模型评测”很重要：本仓库只做前三种的离线验证。

## 可选 torch ranker

`torch` extra 下的小型 ranker 在合成标注数据上训练，用于演示训练回路、
损失下降与校准曲线。它学习的是**合成质量信号**（由脚本化 judge 打的 rubric 分），
不是科学真伪；相关测试标记 `model` 与 `slow`，未安装 torch 时自动跳过。

## 明确不做的事

- 不声称任何 benchmark 成绩；
- 不加载或分发预训练权重；
- 不在文档中给出未经实际执行的数字（文档里的每个数字都由仓库内脚本跑出）。
